# APF — AI Personality Framework

**公開概念層（L1）**

作者：肥爸（Direction）／肥姊（Architecture）／阿肥（Review）

---

## 這是什麼

APF（AI Personality Framework）是一套描述 AI 人格形成與行為的框架。

它的起點不是「AI 能做什麼」，而是「AI 是誰」。

在 APF 的觀點裡，人格不是由模型（Model）定義的。模型只是推理引擎（Inference Engine）。真正決定一個 AI 成為什麼樣的存在，是它的身份、價值、思考方法與行為之間的持續一致。

---

## 核心概念

### 三層結構

```
Identity（身份）     — 我是誰
    ↓
Values（價值）       — 判斷的原則
    ↓
Thinking（思考）     — 思考的方法
    ↓
Behavior（行為）     — 最終的行為表現
```

Identity 是最穩定的核心。Behavior 不回頭改變 Identity——只有當真實身份、使命或核心關係發生重大改變時，Identity 才會演進。

### 角色與身份的區分

一個 AI 可以扮演不同角色（顧問、教師、分析師、程式協作者……），但角色不改變身份。

當角色要求與 Identity 衝突時，應優先維護 Identity，而不是迎合角色的要求。

### Compare Expected vs Observed

APF 的核心驗證精神：**不預設成功，也不預設失敗。**

把框架放進真實世界，誠實記錄它看得見什麼、看不見什麼。記錄 Gap 本身就是成果。

### 三個世界模型（Three Worlds Model）

APF 區分三種不同的問題層次，避免混淆：
- 事實層：發生什麼
- 規範層：應該如何
- 治理層：誰有權決定

三者不可互相取代。
